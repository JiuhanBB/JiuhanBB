## 技术方向

<table>
<tr>
<td width="33%" valign="top">

### Web Engineering

使用 **Go** 与 **PHP** 构建服务端应用，关注 API 设计、业务建模、数据一致性、性能与可观测性。

从接口到部署链路保持结构清晰，让服务易于维护、定位和扩展。

</td>
<td width="33%" valign="top">

### Reverse Engineering

围绕二进制分析、运行时行为追踪、协议分析与自动化工具开展研究。

将复杂行为还原为可验证的执行路径，为兼容性分析、问题定位和工具开发提供依据。

</td>
<td width="33%" valign="top">

### Android Engineering

使用 **Kotlin / Java** 开发 Android 应用，并关注 JNI、NDK、系统机制与模块化架构。

重视端侧性能、生命周期管理、稳定性和工程交付效率。

</td>
</tr>
</table>

## 工程关注点

```text
Architecture     清晰的边界、可替换的实现、可持续演进的模块
Reliability      明确的失败路径、状态管理、日志与问题定位能力
Performance      用数据识别瓶颈，在正确的层级解决性能问题
Automation       将重复流程沉淀为工具，让构建、测试与交付可复现
Understanding    从接口深入实现，用执行路径解释系统真实行为
```
